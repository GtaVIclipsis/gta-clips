GTA Clip Uploader

GTA Clip Uploader is a private, local creator utility designed to format Grand Theft Auto gameplay highlights into vertical 9:16 short-form videos and upload them directly to the creator's own connected accounts via official platform APIs.

1. Vertical 9:16 Formatting

Converts widescreen 16:9 gameplay clips into 1080×1920 vertical videos with blurred framing, facecam layout, voiceover hooks, and burned-in captions.

2. Official API Integration

Uses authorized OAuth 2.0 credentials exclusively via the official TikTok Content Posting API v2 and YouTube Data API v3.

3. Creator-Controlled Publishing

Videos are uploaded as private drafts or inbox items to the creator's own channel for manual review before public release.
